01

学习目标与阅读路线Learning objectives and reading route

ScenarioLibrary 将实验外部条件与本体机理分开：初始化记录描述开始状态，剖面和工况模块产生计划输入，时间模块限定阶段与事件，环境模块提供外生条件或明确的物理边界。它有助于让不同本体在相同条件下进行可解释比较。ScenarioLibrary separates experimental conditions from host mechanisms. Initialisation records describe starting states, profile and operating blocks generate planned inputs, timing blocks define phases and events, and environmental components provide exogenous conditions or explicit physical boundaries. This supports interpretable comparisons under shared conditions.

本指南的核心是“绑定”：有一个场景对象并不意味着本体已经受它驱动。初始化字段必须绑定到 start/fixed，计划信号必须连接到本体输入，物理环境端口必须接入网络。The central concept is binding. Declaring a scenario object does not mean that it drives the host. Initialisation fields must be bound to start/fixed, planned signals connected to host inputs, and physical boundary ports connected into the network.

本指南依据固定提交的源码编写。示例中的数值与曲线描述为源码推导的复现参考，未在本次文档工作中重新运行 Modelica 仿真。This guide documents a fixed source revision. Numerical and curve descriptions are source-derived reproduction references; Modelica simulations were not re-run during this documentation work.

02

理解元件之前，先理解这些概念Concepts to understand before using the components

初始化记录是数据，不是施加初态的执行器Initialisation records are data, not state actuators

ElectricalState、ThermalState 等 record 保存初值与固定标志。只有把字段写进本体组件的修饰项，例如 v(start=state.v_start,fixed=state.fixedV)，才会影响该组件初始化；也不能同时固定过多相互依赖的状态。Records such as ElectricalState and ThermalState store values and fixed flags. They affect initialisation only when bound into host modifiers, for example v(start=state.v_start,fixed=state.fixedV). Avoid overconstraining dependent initial states.

初始猜测与固定初值不同A start guess is not a fixed initial condition

fixed=true 通常把 start 值作为初始化约束，fixed=false 允许求解器结合其他方程确定初值。具体变量的初始化还受本体方程、状态选择与 initType 影响；不能只看到 start 就声称初态已被强制。fixed=true generally imposes the start value as an initial constraint, whereas fixed=false permits initialisation to determine it from other equations. Host equations, state selection and initType also matter; start alone is not evidence that an initial state is imposed.

绝对时间、局部时间和可暂停任务时间不同Absolute, local and pausable mission time differ

绝对时间表直接以仿真 time 为坐标；LocalClock 从参考时刻或触发沿计时；MissionClock 可按其接口暂停。把某一时钟暂停，不会自动暂停所有使用绝对 time 的其他模块。Absolute schedules use simulation time. LocalClock measures elapsed time from a reference or trigger; MissionClock supports pausing through its own interface. Pausing one clock does not automatically pause components that still use absolute time.

半开窗口和右连续表的边界必须明确Declare half-open and right-continuous boundaries

TimeWindow 及阶段窗口通常采用 [开始,结束)，因此结束时刻已经退出。分段常量、命令与模式表在边界采用新值；表的 n、times 和 values 长度必须一致，时间应按具体类的契约有序。TimeWindow and phase windows generally use [start,end), so the end instant is outside. Piecewise-constant, command and mode schedules take the new value at a boundary. Match n, times and values and respect the class-specific ordering contract.

计划结束不等于物理目标完成A completed plan is not a completed physical objective

PhaseSchedule.completed 说明时间轴走完，不说明本体已经停稳或达标。环境 Temperature 的 y 是信号，而 FluidReservoir 等带物理端口的模型会参与网络方程。必须区分计划事实和本体证据。PhaseSchedule.completed means the timetable has ended, not that the plant is settled or compliant. Environment.Temperature.y is a signal, whereas a physically connected FluidReservoir participates in network equations. Distinguish plan status from plant evidence.

因果信号端口用于传递数值或逻辑；电气、机械、热和流体物理端口参与网络方程。不能把物理端口当作普通输入输出，也不能用一个布尔保护请求代替实际的能量或物质通路。Causal signal connectors convey values or logic. Electrical, mechanical, thermal and fluid connectors participate in network equations. A physical connector is not an ordinary signal input, and a Boolean request does not replace an energy or material path.

block AmbientTemperatureCycle "以给定峰时描述可重复的环境温度循环"
  parameter Modelica.Units.SI.Temperature minimumTemperature(min=0) = 288.15 "谷值，K";

排错、适用边界与常见误读Troubleshooting, scope and common misinterpretations

填写了 record，本体为什么没变化Why did the record not change the host?

检查字段是否实际绑定到本体修饰项。record 不是自动搜索并配置组件的程序，未引用的记录不会影响方程。Check that fields are bound into host modifiers. A record does not search for and configure components; an unreferenced record has no effect on the equations.

阶段结束时多触发一次Why did an event occur at a phase boundary?

检查左闭右开的时间定义、右连续表值和事件计数逻辑。输出网格上的重复时刻可能表示事件前后两侧，不应先删掉再判断时序。Check half-open windows, right-continuous values and event-count logic. Repeated timestamps in output may represent the two sides of an event; do not remove them before interpreting timing.

初始化过约束或不一致Initialisation is overconstrained or inconsistent

检查是否固定了连接约束已经决定的从属变量，以及本体是否另外指定 SteadyState 或固定初始方程。先固定独立状态，再让从属量由方程计算。Check fixed dependent variables and any additional SteadyState or fixed initial equations in the host. Fix independent states and let equations determine dependent quantities.

环境信号与物理响应不一致Environmental signal does not affect the plant

检查信号是否接到实际边界或受力关系；单独绘出 300 K、风速或坡度并不表示已作用到本体。Check connection to the actual boundary or force relation. Plotting a temperature, wind speed or grade does not show that it acts on the plant.
